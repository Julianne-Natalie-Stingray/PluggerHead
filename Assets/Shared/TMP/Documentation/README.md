# 随附旧版 TMP 手册

`TextMesh Pro User Guide 2016.pdf` 为 2016 年 12 月、Release 1.0.54 的 14 页原始手册。本轮已逐页提取阅读，保留 PDF 与 meta 原样。当前项目 manifest 与已安装包为 TMP 3.0.6，不能将该 PDF 当作本项目版本的完整操作指南。

| 页码 | 内容与适用边界 |
| --- | --- |
| 1–3 | 版本、版权声明及目录。 |
| 4 | 原 Asset Store/unitypackage 安装与旧创建菜单；本项目已经通过 UPM 引用包，并保存 Essential Resources，不需按旧文档重复导入。 |
| 5–6 | 文本输入、富文本、字体与布局概念；可作为背景，不代表当前 Inspector 字段完整清单。 |
| 7–9 | Bitmap/SDF 材质面板及效果介绍；不同 Shader 支持不同功能，性能描述不等于本项目测量结果。 |
| 10–12 | 旧 Font Asset Creator、图集生成及 Resources 建议；当前本地源码菜单为 `Window > TextMeshPro > Font Asset Creator`，渲染模式与字段以安装版本为准。 |
| 13–14 | 字体、图集、字形与 kerning 数据概念；不是对当前序列化格式的完整定义。 |

字体许可与 Emoji 来源说明分别随资源保存，PDF 的版权说明不能替代它们。当前资源配置见[上级说明](../README.md)。本轮未修改第三方原文或执行字体生成。
